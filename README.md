## Observed ranges

These are ranges from the 20 August 2026 desk pass, not one SKU per brand.

| Field | Range |
|-------|-------|
| Sealed puff listings commonly tracked | About 1,900 to 9,000 |
| Rechargeable names advertising 10,000+ | A different class of device. Do not merge them into the sealed row. |
| Familiar compact tanks | About 2–12 ml, against 22 ml on the reference device |
| Dual battery + e-liquid LED | Uncommon among tracked competitor models |

A missing LED on a unit sold as an Ingot 9000 is an authenticity warning on this catalogue, not a spec variant sold here.
